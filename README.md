# Hi, I'm Diego van Haaster 👋

Software developer based in Trelew, Chubut (Argentine Patagonia 🇦🇷). I've been writing code for quite a while, and on GitHub since 2010. These days I mostly work with **Angular, TypeScript and .NET**, with a particular interest in **OData** and in tools that help frontend and backend talk to each other smoothly.

## 🚀 Featured project

- **[angular-odata](https://github.com/diegomvh/angular-odata)**: a client-side OData library for Angular, written in TypeScript. Models, collections, typed queries and metadata, all integrated with the Angular ecosystem.
